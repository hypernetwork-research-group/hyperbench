# Release notes

This page will contain the release notes for stable versions of HyperTorch.

## Version 0.1.12 - Initial stable release

First stable release of HyperTorch. This release includes the following features:

- Support to build end-to-end training pipeline, from data loading to model training and evaluation.
- Support for hyperlink prediction and node classification tasks.
- Support for benchmarking multiple models on multiple datasets.
- 24 built-in datasets available through [Github](https://github.com/hypernetwork-research-group/datasets) or [HuggingFace](https://huggingface.co/HypernetworkRG).
- Online documentation and ready-to-use examples for using HyperTorch.

For more information, please refer to the [documentation](https://hypernetwork-research-group.github.io/hypertorch/).

Please report any issues with the release on the [HyperTorch issue tracker](https://github.com/hypernetwork-research-group/hypertorch/issues).
